# Phase 4 — Implementation Plan

## Overview
Phase 4 is a breadth expansion: many new features that each plug into the existing architecture. The simulation pipeline gains modules for real estate, debt, and goals. New services handle reporting, API access, and payments.

## Implementation Steps

### 1. Real Estate Module (`simulation/real_estate.py`)
- Model primary residence: current value, appreciation rate (sampled from historical or fixed), mortgage payment schedule, property tax, maintenance
- Rental property: income stream, expenses, appreciation
- Downsizing event: sell at specified age, capture equity minus transaction costs
- Integrate home equity into net worth display (optionally exclude from liquid portfolio)

### 2. Debt Module (`simulation/debt.py`)
- Model debts: balance, interest rate, minimum payment
- Amortization schedule within simulation
- Extra payment allocation: avalanche (highest rate first) or snowball (smallest balance first)
- Debt payoff frees up cash flow for contributions/spending

### 3. Goals Engine (`simulation/goals.py`)
- Goal: target amount, target year, priority
- Goals modeled as lump-sum withdrawals at target year
- Simulation tracks goal achievement probability across runs
- 529/education goals: separate from retirement portfolio

### 4. REST API
- Add `/api/v1/` route group with JSON responses
- Endpoints: `/simulate`, `/snapshots`, `/scenarios`, `/compare`
- API key auth (separate from session auth)
- Rate limiting per key (e.g., 100 requests/hour)
- OpenAPI docs auto-generated by FastAPI

### 5. Report Generator
- PDF report: cover page, input summary, fan chart, key metrics, recommendations
- CSV export: raw simulation percentile data, year-by-year
- Use `weasyprint` (HTML → PDF) to reuse existing Jinja2 templates for report layout

### 6. Payment / Subscription Service
- Stripe Checkout for subscription signup
- Webhook endpoint for Stripe events (subscription created, cancelled, payment failed)
- Tier enforcement middleware: check user's subscription level before allowing premium features
- Free tier: basic simulation (Phase 1 feature set)
- Paid tier: all features (accounts, scenarios, tax modeling, API access, exports)

### 7. Performance Optimization
- Profile simulation with `cProfile` to identify bottlenecks
- Apply Numba `@jit(nopython=True)` to the inner simulation loop
- Cache simulation results keyed on hash of inputs (TTL cache, in-memory or Redis if needed)
- Lazy-load dashboard data (HTMX pagination for snapshot lists)

### 8. Mobile Responsiveness
- Audit all templates with browser dev tools at mobile widths
- Responsive form layouts (stack inputs vertically on mobile)
- Touch-friendly chart interactions (Plotly.js has built-in touch support)
- Test on real devices

## Testing
- Real estate, debt, goal modules: unit tests with known amortization/appreciation schedules
- API: full endpoint test suite with API key auth
- Payment: Stripe webhook signature verification tests (mock Stripe events)
- Performance: benchmark simulation runtime, verify Numba speedup
- Mobile: manual testing on multiple screen sizes
