What this assumes: you set spending once and never adjust it, for the whole period, regardless of how markets behave. Nobody actually does that — a real retiree who trims spending after a bad year does better than these numbers suggest. Treat a row as a reference point, not a budget.

About the 100% row: it means "survived every future we simulated", not "cannot fail". It is set by the single worst path out of the 10,000, so it is the noisiest row here — run the same numbers again and it will move more than any other row. The historical dataset is only about 100 years long, so the far tail is limited by how much history exists, not by the number of simulations. Read the 90–95% rows as the dependable end of the table.
